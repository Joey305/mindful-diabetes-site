# Analytics Event Specification

Use non-identifying analytics only. Do not collect personal health information.

Recommended events:
- `resource_card_view`
- `resource_pdf_download`
- `resource_pdf_open`
- `resource_share_click`
- `resource_newsletter_click`
- `resource_donation_click`

Recommended fields: `guide_title`, `guide_slug`, `resource_page_url`, `referring_page`, `button_position`, `device_category`, `download_format`, `timestamp`.
